# AGENTS.md

## Cursor Cloud specific instructions

### Services

| Service | How to run | Notes |
|---------|------------|-------|
| PostgreSQL | `docker compose up -d postgres` | Required for API and migrations |
| Backend API | `cd backend && uvicorn app.main:app --reload --host 0.0.0.0 --port 8000` | Run `alembic upgrade head` and `python scripts/seed.py` first |
| Frontend | `cd frontend && npm run dev` | http://localhost:3000 |

Full stack: `docker compose up -d` from repo root (frontend :3000, API :8000).

### Lint / test / build

- Backend tests: `cd backend && python -m pytest tests/ -q`
- Frontend build: `cd frontend && npm run build`
- No dedicated ESLint script in `package.json`; rely on `npm run build` for type checks.

### Platform vs lab apps

- Platform super-admin UI defaults to **English** (`useLocale("platform")`).
- Lab app defaults to **Arabic**.
- Platform routes live under `/platform/*`; lab routes under `/(lab)/*`.

### Common gotchas

- After dependency installs, restart dev servers if hot reload does not pick up new packages.
- Production deploy on VPS: `docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build` plus `alembic upgrade head` in the backend container.
- **Admin passwords:** bootstrap creates `superadmin` / `labadmin` only if missing (initial password from `PLATFORM_ADMIN_PASSWORD` / `DEMO_ADMIN_PASSWORD`) and never resets them on restart. Recover with `python scripts/ensure_platform_admin.py --reset 'NewPass'`. Production refuses the default `SECRET_KEY`.
- **Subscriptions:** `TenantAccessService.assert_tenant_active` cuts off labs after `grace_ends_at` (demos at `expires_at`). Demos are `TRIAL` tenants; pausing one cancels its subscription rather than changing status.
- **Permissions:** declare checks as `user: User = require_permission("code")` — never `user: CurrentUser = require_permission(...)` (FastAPI silently ignores it; `tests/test_permissions_enforced.py` guards this). The catalogue and default roles live in `app/core/rbac.py` and are ensured in every lab DB on login. The frontend hides pages via `pagePermission()` in `src/lib/modules.ts`.
- **Money figures:** "collected" is always by payment date (`Payment.paid_at`); "outstanding" is what's still owed on invoices issued in the period; test margin is after invoice discounts.
- **Demo links:** `/demo?token=…` → `POST /auth/demo-login` signs in as the demo lab admin; the token is a JWT expiring with the demo.
- Platform tenant feature saves can 500 if admin password fields are sent unchanged; tenants edit flow uses `passwordDirty` to avoid that.
- **Data “missing” after re-login:** usually wrong tenant DB routing or data left in platform DB. On login, missing rows are synced from platform → dedicated DB. Manual repair: `docker compose ... exec backend python scripts/sync_tenant_data_from_platform.py <lab-code>`.
- **Backups:** No backup container. Host cron runs `deploy/hostinger/run-backup.sh` daily at 02:00 into Docker volume `labmaster_backups`. Install: `sudo bash deploy/hostinger/install-backup-cron.sh`. Manual: `sudo bash deploy/hostinger/run-backup.sh`. After VPS reboot: `bash deploy/hostinger/post-reboot.sh`.
- Login screen pre-fills last laboratory code from `labmaster-auth` — customer must use the same code every time.
- Tests catalog list has **no default date filter**; transactional pages (patients, billing) still filter by date range.
- **A4 result reports:** Generated by `LabReportPdfBuilder` with Noto Arabic fonts (`backend/app/assets/fonts/` for dev; Dockerfile downloads fonts into `/usr/share/fonts/truetype/labmaster/`). After Dockerfile changes, production deploy needs `FULL_REBUILD=1 sudo bash deploy/hostinger/quick-update-production.sh`.
- **CBC result entry:** Tests with code `CBC` use the standard parameter list (Hb, RBC, WBC, differential, etc.) when no custom template exists.
